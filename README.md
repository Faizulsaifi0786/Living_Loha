# Livingloha Enterprises — From Scratch

## 1. Install Node.js

Install Node.js LTS on your computer.

## 2. Open this project

Open the folder in VS Code.

## 3. Open terminal

Inside the project folder run:

npm install

Then:

npm run dev

Vite will show a local address such as:
http://localhost:5173

## 4. Build for hosting

npm run build

The final production website will be inside the `dist` folder.

## 5. Where to edit things

All website content is in:

src/App.jsx

All design/CSS is in:

src/styles.css

The starting page is:

index.html

React starts from:

src/main.jsx

## 6. Updating service photos

Each service uses one image. Replace its `image` path in `src/App.jsx` and add the
file under the matching folder in `public/images/`. For example:

```js
image: "/images/gates/my-gate.jpg"
```

The home hero photo is set in `src/styles.css` at `/images/livingloha-fabrication-workshop-exterior.png`.
